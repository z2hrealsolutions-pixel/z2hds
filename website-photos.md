# Website photos: names and descriptions

The 34 photos from "Photos for website", renamed for the web. Each name says what the photo shows and which studio it belongs to, which helps Google and AI search tools understand the picture. The description is the text read out by screen readers and shown to search engines.

No photo had hidden location data. Portrait statues show real people: get each customer's permission before the site goes live (see the notes at the end).
