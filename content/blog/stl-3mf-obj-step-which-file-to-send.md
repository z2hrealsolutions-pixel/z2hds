If you have never sent a 3D file before, the names can be confusing. Here is what each one means.

## The file types

| File | What it holds | Instant price |
|---|---|---|
| **STL** | The shape only. No colour. The most common file for 3D printing. | Yes |
| **3MF** | The shape, and often the colours and print settings too. | Yes |
| **OBJ** | The shape. Common when a model is downloaded or scanned. | Yes |
| **STEP** | A CAD file used in engineering. Exact, editable geometry. | Send on WhatsApp |

## A note on colour

Our estimator reads colours from 3MF files saved in Bambu Studio or Orca Slicer. STL and OBJ files do not carry colour in a way the estimator reads, so the page has a box to tick if you want more than one colour. The price range is wider in that case.

## Before you upload

- **Use millimetres.** If your model looks tiny or huge in the preview, the units may be wrong.
- **Check it is one solid shape.** Models with holes in the surface can print badly. If the preview looks odd, tell us.
- **Parts bigger than the printer** are still fine. They are printed in pieces and joined, and the estimate counts the pieces.

## No file? You still have options

- **A photo or sketch.** We can draw it in CAD. See [3D modelling and CAD](/services#3d-modelling-cad).
- **A broken part.** Send it or a photo with measurements, and we can copy or repair it.
- **A person.** Send photos and we can make a statue. See [custom figurines](/services#custom-figurines).
